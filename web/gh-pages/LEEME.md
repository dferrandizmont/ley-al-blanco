# Redirección de GitHub Pages

Hasta el 30-oct-2026 la política se publicaba en GitHub Pages (`https://dferrandizmont.github.io/ley-al-blanco/`, rama
`gh-pages` del repo público). Ahora la web es https://leyalblanco.mainshai.com, generada por mainshai-web desde `web/`.

Estas dos páginas redirigen las URL antiguas (que siguen en builds ya publicados y en las fichas de las tiendas) a las
nuevas. Para publicarlas, sustituye el contenido de la rama `gh-pages` del repo público por el de esta carpeta (sin este
LEEME), con un único commit de `Daniel Mont Ferrandiz <dev@mainshai.com>`.
